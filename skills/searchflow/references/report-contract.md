# 보고서 산출 계약 — 채워질 칸 목록

> 이 파일은 **행동 지시가 아니라 칸 목록**이다. 어느 모델이 돌든 같은 칸이 채워져야 한다.
> 칸이 비면 비었다고 쓴다 — 조용히 생략하는 것과 "해당 없음"이라고 쓰는 것은 다르다.

## 1. 필수 칸

| 칸 | 내용 | 비면 안 되는 이유 |
|---|---|---|
| **as-of 표기** | 자료 시점 + **"왜 더 최신이 없는가" 1줄** | 시점 없는 사실은 언젠가 조용히 거짓이 된다 |
| **관찰 범위 선언** | 몇 개 중 몇 개를 실제로 읽었나. 표본이면 표본이라고 | 전수와 표본을 같은 문장으로 쓰면 독자가 구분할 방법이 없다 |
| **내부/사전 조회 근거** | 조사 전에 이미 아는 것을 확인했는지 (순정 환경은 가능 범위 명시) | 이미 답이 있는 질문을 새로 조사한 비용 |
| **인용** | **verbatim + 출처.** 원문 대조 없는 인용은 산출하지 않는다 | 요약이 인용으로 둔갑하면 반증이 불가능해진다 |
| **부재 단정 근거** | "없다"는 boundary(범위 확장) + isolation(격리 입력) 확인 후에만 | 관찰 부족이 부재로 둔갑하는 것이 가장 흔한 오류 |
| **시점 라벨 게이트** | "출시·등장·최초" 류는 발표 일자 대조 후에만 | 라벨은 값보다 먼저 죽는다 |
| **사용불가 원장** | 무엇을 왜 버렸나 | 버린 기록 없는 보고서 = 처음부터 그것만 본 보고서와 구별 불가 |
| **공백 선언** | 확인하지 못한 영역 | 공백을 적으면 가점이다 — 숨기는 게 유리해지지 않게 |
| **실행 증명** | 주장이 아니라 돌려본 결과 (명령 · 출력 · 종료코드) | "확인했다"는 확인이 아니다 |
| **방법론 출처** | 어떤 절차로 이 결론에 왔는지 1줄 | 재현 가능성의 최소 단위 |
| **전제 반문 1개 + 답** | 이 결론이 설명하지 못하는 관측이 있나 | 자기 점검은 자인("과했을 수 있다")이 아니라 답해야 하는 질문이어야 한다 |
| **종료 조건 성적표** | 선언한 시한/기준 대비 **어디서 멈췄나** | 시간이 남아 끝난 것과 시한에 걸려 끝난 것은 다른 결과다 |
| **환경·한계** | enhanced 격하 라벨 (교차 엔진 미수행 · parallelism · 브라우저 도구 부재 등) | 축소된 조사를 완전한 조사처럼 읽히게 하지 않기 위해 |
| **점수 지위** | 이 보고서의 점수·등급이 **확정 체계인지 잠정 체계인지** 1줄. 잠정이면 `점수 체계 = 잠정(held-out 미검증)` 문구를 그대로 싣는다 | 숫자는 그 자체로 확정처럼 읽힌다 — 지위를 안 적으면 잠정값이 실측 지표로 인용된다. 이 칸이 **가중치 확정 전에도 공개할 수 있게 하는 조건**이다 |

## 2. 검증 서술 규율

- **검증 단계 전건은 양성/음성 대조를 동반한다.** 양성 대조 = 있는 것을 넣어 검출되는지 · 음성 대조 = 있을 수 없는 것을 넣어 안 걸리는지.
- **`0건` · `cannot verify` · `read 실패` 는 통과가 아니라 전용 상태다.** 화면상 "문제 없음"과 "검사기가 죽었음"이 같아 보이므로, 0건을 보고할 때는 그 검사기가 이번 실행에서 무엇을 잡아냈는지 함께 적는다.
- 수치를 인용할 때는 **무엇을 어떤 단위로 셌는지** 붙인다(라인/매칭/파일/문서 중 무엇인가). 같은 자료가 단위에 따라 다른 값으로 갈린다.

## 3. 점수 표기

- **점수와 미충족 축은 사용자에게 공개한다.**
- **가중치·문턱은 공개하지 않는다.** 사용자에게 보여도 되는 것과, 조사를 수행하는 워커가 알아도 되는 것은 다르다 — 후자는 0이다.

## 4. 언어

machine 필드(원장 · 스크립트 출력)는 UTF-8 · ISO-8601+offset · enum 은 ASCII 고정. **산문만 사용자 언어를 따른다.**
