# 합성 템플릿 — 모은 것을 배열하는 층

> 조사 축이 아니다(`frames.md` §3). **템플릿은 조사를 늘리지 않는다** — 칸을 채우려고 추가 조사를 하면 그게 낭비다.
> 이 파일에는 판정 기준 수치가 없다. 그 층은 리드 전용 문서에만 있고 워커 프롬프트 조립 경로가 그 파일을 열지 않는다(`SKILL.md` §P2.5).

## 0. 세 줄 규율

1. **빈 칸은 빈 칸으로 둔다.** 지우지 않고 "확인 못 함"이라 적고 「공백 선언」에 올린다. 조용히 없앤 칸과 채우지 못한 칸은 독자에게 같아 보인다.
2. **템플릿 선택을 산출물에 적는다.** 무엇을 썼는지 안 적으면 왜 이 배열인지 재현할 수 없다.
3. **표의 각 칸은 원장 `source_id` 를 끌고 온다.** 출처 없는 칸은 합성이 아니라 창작이다.

## 1. 유형 → 기본 템플릿

| 유형 | 기본 템플릿 | 칸 |
|---|---|---|
| `factcheck` | **판정표** | 주장 · 근거(source_id) · 등급 · 판정(참/거짓/부분참/판정불가) |
| `market` · `company` | **PESTEL** / **SWOT** / **5 Forces** 중 질의에 맞는 것 | 각 축 1행 + 해당 축의 source_id · 빈 축은 "확인 못 함" |
| `policy` | **이해관계자 매트릭스** | 이해관계자 · 이해(무엇을 얻/잃나) · 근거 조문·자료 · 입장 확인 여부 |
| `compare` | **축×후보 표** | 행=축 · 열=후보 · 칸=관측값 + source_id · 미확인 칸은 공란 아니라 "미확인" |
| `person` | **확인된 사실 목록** | 사실 · 1차 출처 · 시점. 공개 직무 사실만(`frames.md` §1 특칙) |
| `tech` | **작동/한계/대안 3열** | 공식 스펙 근거 · 실사용 보고 근거 · 실패 사례 근거 |
| `discovery` | **지형도** | 주요 개념 · 최신 동향 · 이견. 판정하지 않는다(열린 탐색) |

복합 유형이면 **주 유형 템플릿 1개**를 기본으로 하고 부 유형은 절로 붙인다. 템플릿 2개를 나란히 놓으면 같은 자료가 두 표에 중복 등장하며 분량이 근거처럼 보인다.

## 2. 판정표 — `factcheck` 스켈레톤

```markdown
| # | 주장 | 근거(source_id) | 등급 | 판정 |
|---|---|---|---|---|
| 1 | <검증 대상 주장 그대로> | s001, s004 | ORIGINAL / A / B / C / UNREACHABLE | 참 / 거짓 / 부분참 / 판정불가 |
```

- **`판정불가` 는 정상 결과다.** 근거가 부족하면 부족하다고 적는다 — 억지 판정보다 정직한 판정불가가 싸다.
- **부분참은 무엇이 참이고 무엇이 거짓인지 나눠 적는다.** "부분참" 단독은 정보가 아니다.
- 지지 축과 반증 축의 근거를 **같은 행에 나란히** 놓는다. 지지만 있는 행은 반증 축이 빈손이었다는 뜻이므로 그렇게 적는다.

## 3. 이 층에서 자주 죽는 것

- **라벨**: "최초·유일·정식·표준" 은 값보다 먼저 죽는다. 표에 그 단어를 쓸 때는 그 라벨이 어느 문서 기준인지 같은 칸에 적는다(같은 값이 문서마다 다른 라벨로 불린다).
- **단위**: 표의 수치는 무엇을 어떤 단위로 셌는지 붙인다. 단위 없는 수치는 같은 자료에서 여러 값으로 갈린다.
- **as-of**: 표 자체에 시점을 붙인다. 행마다 시점이 다르면 행에 붙인다.
- **재보도 중복**: 같은 원본을 옮긴 기사 여러 건이 한 칸에 나열되면 근거가 여러 개처럼 보인다. 독립 경로 셈은 `acquisition.md` §4 를 따르고, 접은 것은 원장에 남긴다.

## 4. 표를 만들지 않는 경우

- 축이 2개 이하 → 산문 2문단이 표보다 읽기 쉽다.
- 칸의 절반 이상이 "미확인" → 표가 공백을 격자로 위장한다. 그때는 **확인된 것만 목록**으로 쓰고 나머지는 「공백 선언」에 몰아 적는다.
- 질의가 판정을 요구하지 않는 열린 탐색(`discovery`) → 지형도는 표가 아니어도 된다.
