# [FIXTURE] SearchFlow 보고서 — RFC 9110 과 상태코드 418

> ⚠️ **검사기 fixture 다.** 칸이 전건 채워진 형태를 보이기 위한 표본이며, 이 문서를 사실 출처로 인용하지 말 것.
> 본문 근거는 2026-07-31 스폰 스모크에서 워커가 실제로 반환한 산출을 축약한 것이다.

## 판정

`factcheck` — **거짓 (부분참 아님)**: RFC 9110 은 418 을 "I'm a teapot" 으로 등재하지 않는다. `(Unused)` 로 **예약**만 한다.

|---|---|---|---|---|
| 1 | RFC 9110 이 418 을 정식 상태코드로 등재한다 | s001, s002 | ORIGINAL | 거짓 |
| 2 | 418 의 최초 정의는 만우절 RFC 다 | s003 | ORIGINAL | 참 |

## as-of 표기

자료 시점 = 2026-07-31. RFC 9110(2022-06 발행) 이후 418 항목을 바꾼 후속 표준 문서는 확인되지 않았다 — **더 최신이 없는 이유**: 상태코드 등록부가 갱신되면 등록부 자체에 반영되며, 등록부 조회 시점이 오늘이다.

## 관찰 범위 선언

1차 출처 3종(표준 문서 본문 · 상태코드 등록부 · 원 만우절 문서)을 **전수 실독**했다. 2차 자료(블로그·해설)는 조사 범위에서 제외했다 — 1차로 판정이 닫혔으므로 추가 조사가 판정을 바꾸지 않는다. 접은 축: 없음.

## 내부/사전 조회 근거

순정 환경이라 내부 지식 저장소 조회는 불가. 조사 전 리드가 아는 것("418 은 농담 코드")을 가설로만 두고 1차 출처로 재확인했다 — 가설을 근거로 쓰지 않았다.

## 인용

- s001 (표준 문서 본문, verbatim): `15.5.19.  418 (Unused)` / `Therefore, the 418 status code is reserved in the IANA HTTP Status Code Registry.`
- s002 (등록부, verbatim): `418 | (Unused) | [RFC9110, Section 15.5.19]`
- s003 (만우절 문서, verbatim): `Any attempt to brew coffee with a teapot should result in the error code "418 I'm a teapot".`

## 부재 단정 근거

"418 을 정식 등재한 후속 표준은 없다" 는 단정의 근거: ① **boundary** — 등록부 전체 행을 확인(418 만 조회한 것이 아니다) ② **isolation** — 원 문서의 표준 등급 필드를 따로 조회해 표준 트랙 승격 이력이 없음을 확인. 두 축 통과 후 단정.

## 시점 라벨 게이트

"정식 · 등재 · 표준" 라벨은 문서마다 다른 의미로 쓰인다. 이 보고서에서 **등재** = 등록부에 행이 존재함 / **정식 상태코드** = 그 행이 의미를 배정받았음. 418 은 앞은 참, 뒤는 거짓이다 — 두 라벨을 한 단어로 덮으면 판정이 뒤집힌다.

## 사용불가 원장

- s004 `UNREACHABLE` — 커뮤니티 토론 경로. robots.txt 전면 불허(`Disallow: /`), **우회하지 않음**.
- s005 `discarded` — 표준 문서를 옮겨 적은 해설 기사. `discard_reason` = 재보도 — 독립 경로 아님.

## 공백 선언

- 이 환경에서 웹 검색 도구가 오류로 동작하지 않아 취득 경로가 HTTP 직접 취득으로 한정됐다. 검색으로만 닿을 수 있는 자료는 미확인.
- RFC 9110 이전 판(구 명세) 등록부의 418 표기 변천사는 확인하지 못했다.

## 전제 반문 1개 + 답

**반문**: 이 결론이 설명하지 못하는 관측이 있나 — 실제 서버·프레임워크가 418 을 반환하는 사례가 다수 있는데, 그건 "등재됐다"는 뜻이 아닌가?
**답**: 아니다. 등록부는 418 을 배정 불가로 예약해 뒀고, 구현체가 관습적으로 쓰는 것과 명세가 의미를 배정한 것은 다른 층이다. 다만 **"쓰이지 않는다"고 말하면 그건 거짓**이므로, 판정은 "명세상 미배정 · 구현상 관습적 사용"으로 두 층을 나눠 적었다.
